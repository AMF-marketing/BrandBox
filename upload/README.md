# BrandBox

Существующий проект обновлён 20 октября 2026 года. Next.js, React, TypeScript, Tailwind CSS. Готовый статический экспорт находится в `out/`.

## Посмотреть готовый сайт

1. Распакуйте архив и откройте папку `brandbox`.
2. В PowerShell выполните `./START.ps1`, либо в терминале — `node serve.cjs out`.
3. Откройте http://127.0.0.1:3000 в обычном браузере. Сервер работает до Ctrl+C. START.ps1 по умолчанию использует порт 3001; команда node serve.cjs out — порт 3000.

Нужен Node.js. Зависимости для просмотра готовой сборки устанавливать не требуется. Если порт занят, остановите старый сервер либо задайте `PORT=3001` через переменную окружения перед запуском.

## Разработка

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

Конфигурация Babel сохранена для совместимости с Windows. Новые зависимости в этой доработке не устанавливались.

## Проверки

- TypeScript и production build: успешно.
- 14 регрессионных проверок маски и валидации: `npm run test:form`.
- 9 HTTP-проверок страниц, ресурсов и 404: `npm run test:http`.
- Проверка ссылок, ресурсов, якорей и SEO-метаданных всех HTML-файлов: `python scripts/check-export.py`.
- Браузерные клики, визуальная проверка и Lighthouse не выполнены: браузерная политика блокирует localhost. Результаты автоматических проверок: `VERIFICATION.json`.

Для ручной проверки откройте ширины 320, 480, 768, 1024 и 1440 px. Проверьте мобильное меню, фильтры, страницы товаров, FAQ, три шага заказа, ошибку неполного номера, обязательное согласие, закрытие диалога по Escape и возврат фокуса. Завершение демоформы ничего не отправляет.

## Серверный режим и публикация

Сервер заявок подготовлен, но получатель не подключён. Подробная инструкция, контракт получателя и перечень переменных: DEPLOYMENT.md и .env.example.

`npm run build:server` и `npm run start:server` запускают Next.js с API `/api/orders/`. Обычная `npm run build` сохраняет статический деморежим. UI, поля и валидация формы сохранены. Включение настоящей отправки требует полного набора серверной конфигурации и утверждённых документов.

Выполнены 31 серверная проверка с имитацией внешних сервисов (`npm run test:orders`) и 12 HTTP-проверок настоящего Next.js-сервера с отключённой доставкой (`npm run test:server-http`, после серверной сборки). Реальная доставка и клики в браузере не проверялись.
