## Как загрузить обновление
Распакуйте BrandBox-SEO-update.zip. На главной странице репозитория AMF-marketing/BrandBox выберите Add file → Upload files. Перетащите всё содержимое папки «upload» (app, components, lib и другие файлы), а не саму папку upload. Вложенность должна сохраниться. Сохраните через Commit changes. Изображения и весь проект заново загружать не нужно. Cloudflare начнёт сборку автоматически.

В Cloudflare проверьте Settings → Variables and Secrets: если задан NEXT_PUBLIC_SITE_ORIGIN, он должен равняться https://brandbox.pages.dev. Если переменной нет, сработает новый адрес по умолчанию. Старый адрес в переменной переопределит изменения кода.

## После успешной сборки
1. Откройте /robots.txt: Allow: / и Disallow: /api/. Откройте /sitemap.xml: все адреса должны начинаться с https://brandbox.pages.dev/.
2. Добавьте сайт в Яндекс Вебмастер и Google Search Console. Для проверки по HTML-тегу доступны переменные NEXT_PUBLIC_YANDEX_VERIFICATION и NEXT_PUBLIC_GOOGLE_VERIFICATION: укажите только значение content, затем пересоберите сайт. Это проверочные коды, не пароли. Можно использовать проверку HTML-файлом: файл кладётся в public.
3. Отправьте sitemap.xml и главную страницу на переобход. Доступ к аккаунтам поисковых систем в рамках этой работы не предоставлялся; фактическая регистрация и переобход не выполнялись.
4. После подключения своего домена смените NEXT_PUBLIC_SITE_ORIGIN и настройте перенаправление на основной домен. Страницы preview-деплоев не следует продвигать как самостоятельные сайты.
5. Подтвердите данные карточки организации в Яндекс Бизнесе/2ГИС, если карточка есть. Не обозначайте квартиру как доступный пункт самовывоза без фактической возможности приёма клиентов.

Форма сохраняет честный деморежим. Для коммерческого запуска нужно отдельно подключить обработку заявок и утвердить сведения об операторе персональных данных. Индексация и позиции не гарантируются; результаты оценивают после переобхода по данным поисковых систем.
