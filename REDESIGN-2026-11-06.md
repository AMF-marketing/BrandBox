# Обновление BrandBox от 06.11.2026

Обновлён существующий проект из репозитория AMF-marketing/BrandBox, ветка main. Цены, 19 товаров, их фотографии, контакты и существующие адреса сохранены. Автоматическая публикация из этой среды не выполнялась.

## Выполнено

- Первый экран: H1 «Изготовление печатей и штампов в Новосибирске за 30 минут», отдельный акцент на сроке, подзаголовок без повторения H1 и кнопка «Заказать печать».
- Четыре предложения в начале лендинга: логотип, шоколадный подарочный набор, маркетинг и комплект автоматической и карманной печатей со скидкой 15%. Три CTA открывают общую форму и сохраняют выбранное предложение. Для шоколадного набора кнопка отсутствует до задания HTTPS-ссылки партнёра.
- Вместо круглой аватарки используется векторная версия оранжевого куба с надписью BrandBox по предоставленным материалам. SVG подготовлен как веб-версия по визуальному образцу; автоматический точный экспорт кривых из CorelDRAW не выполнялся. Надпись преобразована в контуры, чтобы отображение не зависело от шрифтов посетителя. Логотип и первый экран можно оценить по скриншотам.
- Четыре коротких образца отзывов без фото, явно помеченные как образцы для согласования. Они не включены в Review/AggregateRating-разметку и не выдаются за реальные отзывы. Кнопка «Оставить отзыв» открывает письмо на brandboxy@mail.ru; отправку пользователь выполняет сам в своём почтовом приложении. Сайт не заявляет, что письмо уже отправлено.
- Всплывающее предложение 400 ₽: только компьютер с точным указателем, не раньше 30 секунд после загрузки страницы, при уходе курсора через верхнюю границу. На мобильных автоматического показа нет. Не открывается поверх другой формы. Крестик, Escape и закрытие по затемнению скрывают предложение на 7 дней. Подтверждённая заявка отключает дальнейший показ в этом браузере.
- Всплывающая форма: имя, маска телефона, обязательное согласие, рекламное согласие выключено по умолчанию. Telegram и WhatsApp скрыты до фактического подключения. Работают клиентская и серверная проверки, общая антиспам-защита, повторные попытки и сообщения об ошибках. Метка передаётся как source=exit-popup, promotion.id=exit400, promotion.label=«Скидка 400 ₽ / Exit Popup». ID и источник предложения проверяются на сервере, а не произвольно принимаются из браузера.
- Cookie: компактная оранжевая карточка, сохранение выбора, закрытие и отдельная настройка внешней карты. Аналитика и рекламные пиксели отсутствуют. Карта Яндекса не загружается до отдельного разрешения; координаты и точка адреса сохранены. Отзыв разрешения выгружает карту. В футере доступны настройки cookie. Тексты политики обновлены под фактическое хранение.
- 150 запросов из BrandBox_semantika_corrected.xlsx распределены в SEO-SEMANTICS.csv без суммирования пересекающихся частот. Отдельные страницы добавлены для самозанятых и штемпельных подушек. Обновлены метаданные, внутренняя навигация, карта сайта и изображения для соцсетей. Названия моделей не менялись.

## Что нужно уточнить

1. Заменить помеченные образцы отзывов реальными согласованными текстами и именами.
2. Уточнить стоимость и состав работ по логотипу, условия и содержание промокода. Они не выдуманы и не объявлены бесплатными.
3. Добавить ссылку партнёра в NEXT_PUBLIC_CHOCOLATE_PARTNER_URL. До этого неработающей кнопки нет.
4. Утвердить условия скидки 400 ₽ и ограничения совмещения акций. Место предусмотрено в lib/campaigns.ts: discountTerms. Сейчас посетителю прямо сообщается, что условия уточняются при согласовании заказа. Автоматическое применение скидок к неподтверждённому составу заказа не реализовано.
5. Для реальных заявок подключить серверный режим, Turnstile, общий лимитер и получателя webhook по DEPLOYMENT.md. Статический Cloudflare Pages остаётся демоверсией: он не исполняет Next.js API. Секреты хранятся только на сервере. Потребуются утверждённые сведения об операторе и документы до включения реального сбора данных.
6. При подключении Telegram или WhatsApp включить соответствующие NEXT_PUBLIC_* и ORDERS_* флаги вместе, только когда выбранный канал фактически обслуживается. Подключение не имитируется.

## Установка обновления через браузер GitHub

1. Распакуйте BrandBox-update-2026-11-06.zip.
2. Откройте распакованную папку. Сразу внутри должны быть app, components, lib, public, server, scripts и файлы проекта.
3. Откройте https://github.com/AMF-marketing/BrandBox/upload/main.
4. Перетащите всё содержимое распакованной папки. ZIP и саму внешнюю папку в GitHub не загружайте. Дополнительной папки upload в архиве нет.
5. Нажмите Commit changes. Существующие файлы заменятся, остальные сохранятся. Фотографии каталога повторно не нужны.
6. Дождитесь новой успешной сборки в Cloudflare Pages. Команда npm run build, выходная папка out, ветка main. Проверьте, что NEXT_PUBLIC_SITE_ORIGIN, если задана, равна https://brandbox.pages.dev.
7. Откройте сайт с обновлением Ctrl+F5. В карточке Deployments должна быть зелёная галочка именно у нового коммита.

Для локальной разработки: npm ci, npm run dev. Для проверки: npm run typecheck, npm run build. Готовую сборку можно открыть через node serve.cjs out. Подробности реальных проверок и ограничений — REDESIGN-VERIFICATION.json; скриншоты подготовлены отдельно.

Восстановление по оттиску, изготовление дубликатов, печати для государственных учреждений, штампы для упаковки, цвета краски, доставка и специальные требования не объявлены гарантированными услугами или наличием без подтверждения. Упоминания соответствуют смыслу запросов и предлагают уточнить возможность заказа.
