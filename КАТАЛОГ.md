## Обновление фотографий

По запросу заказчика у 17 уникальных снимков удалён фон встроенным инструментом image_gen. На сайте используются PNG с прозрачностью и общий светлый фон с оранжевым акцентом. Сами модели, их названия и цены сохранены. Порядок карточек изменён. Исходные файлы сохранены отдельно, параметры обработки и контрольные суммы — в IMAGE-PROCESSING.json. Генеративная вырезка может менять мелкие детали краёв; для печатных материалов следует использовать оригиналы.

Все 19 позиций представлены в каталоге на главной странице. Навигация ведёт к разделам лендинга, заказ открывается из карточки без переходов. Каталог поддерживает категории, поиск по названию, типу и размеру, сортировку по цене и сброс выбора. Старые URL сохранены для совместимости. Названия и цены прежние.

Вместо прежних вырезок подключены новые изображения, созданные встроенным image_gen по исходным фотографиям: изменены камера, композиция и свет. Это иллюстрации по референсам, а не новая физическая фотосъёмка; мелкие детали и невидимые стороны могут отличаться. Исходники сохранены. Полные запросы, соответствия товаров и контрольные суммы — IMAGE-PROCESSING.json. Проверки выбора: npm run test:catalog-selection.
